# Stats website

**Role:** website builder.

**Waits on:** the app being used for real games. Low priority.

**Owns:** `website/` (new folder) and an export button added to the app by the lead builder.

## Deliver

A small public website with our season stats, game results and box scores, at `mikeyjarrell.com/baseball/`, hosted free on GitHub Pages.

1. **Export:** the app writes one file with the season’s finished games (via the share sheet, to AirDrop or Files).
2. **Build:** a script on Mac turns that file into the website’s pages. Mikey runs one command to publish.
3. **Pages:** season batting and pitching tables, a page per game with the newspaper box score, a page per player.

## Before building

Ask Mikey: are teammates fine with their names and stats on a public page, or should it show first names or initials only? Should the site be unlisted (no search engine indexing)?
